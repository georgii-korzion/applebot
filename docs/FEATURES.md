# Apple Drop Assistant — что есть в расширении

Расширение для Chrome, которое помогает оформить предзаказ iPhone на apple.com/ae в момент старта продаж. Оно само ждёт открытия, кладёт товар в корзину, проходит гостевое оформление с самовывозом и доводит заказ до оплаты. Подтверждение оплаты (Apple Pay на телефоне, банк в приложении) всегда делает человек.

Целевой дроп: iPhone Duo, 16.10.2026, 16:00 по Дубаю. Тесты — на iPhone 18 Pro, который уже продаётся.

---

## 1. Кнопки в окне расширения (popup)

| Кнопка | Что делает |
|---|---|
| **Start** | открывает окно с вкладками на странице нужного iPhone и запускает весь процесс |
| **Stop** | останавливает все вкладки профиля |
| **Prepare** | прогрев профиля заранее: проверяет страну, очищает корзину, открывает страницу товара и пишет, всё ли в порядке |
| **Clean bag** | очищает корзину профиля |
| **Следующий на оплату** | вручную передать очередь оплаты следующей вкладке/профилю |
| **Ассистент: вкл/выкл** | включает режим, где важные кнопки жмёт человек (см. §8) |
| **Экспорт лога** | сохраняет лог в файл |
| **Очистить лог** | очищает лог |
| **Экспорт заказов (CSV)** | таблица всех заказов для Excel/Numbers |
| **Настройки** | открывает страницу настроек |

Ещё в popup видно: профиль, режим (auto/assist), подключён ли хаб, на какой сайт смотрит расширение (apple.com или тестовый мок), список вкладок с их состоянием, последние заказы и хвост лога. Ошибки и предупреждения настроек показываются сразу.

## 2. Настройки

Заполняются формой или импортом JSON. Кнопка **«Проверить и сохранить»**: если есть ошибка, настройки **не сохраняются**, сверху красный список того, что поправить.

### Профиль

| Поле | Что это |
|---|---|
| profileId | имя профиля (drop-1, drop-2…), у каждого профиля Chrome своё |
| Хаб | адрес хаба `ws://127.0.0.1:8765`, пусто — без хаба |
| openAt | время старта продаж, например `2026-10-16T16:00:00+04:00` |
| Режим | auto — кнопки жмёт расширение; assist — критичные кнопки жмёт человек |
| baseUrl | `https://www.apple.com` (тестовый мок — только в dev-сборке) |

### Заказ

| Поле | Что это |
|---|---|
| id, priority | название заказа и его место в очереди оплаты |
| profiles | какие профили ведут этот заказ |
| вкладок в профиле | сколько вкладок открыть (обычно 2–3) |
| targets | парт-номера нужных iPhone по приоритету |
| stores | магазины самовывоза по приоритету (Dubai Mall, Mall of the Emirates, Al Maryah, Yas Mall, Al Jimi) |
| Город | город самовывоза в чекауте |
| Слот: день / после / до | желаемый день и время окна самовывоза |
| Оплата | applepay или manual (карта) |
| Фолбэк Apple Pay | если Apple Pay нет — перейти на карту |
| Фолбэк карты | если поля карты не загрузились за 10 с — перейти на Apple Pay |
| Имя, Фамилия, Email, Мобильный | получатель заказа (реальный человек, телефон `05XXXXXXXX`) |
| Карта: номер, срок, CVV, имя | карта для автозаполнения; пусто — вводит человек |
| Плательщик: имя, фамилия, улица, Area, Town, город, Title | адрес плательщика (Billing Address), обязателен при оплате картой |
| Нажимать Review самим | расширение само нажимает «Review Your Order» |
| Нажимать Place Order самим | при карте расширение само нажимает «Place Order» один раз; банк подтверждаешь ты |
| Фолбэк доставки + адрес | если самовывоза нет нигде — оформить доставку |

В правой части страницы — весь конфиг в JSON: импорт, экспорт, тонкие настройки времени (как часто обновлять, сколько ждать).

Проверки при сохранении: имя, фамилия, email и телефон заполнены правильно; парт-номера и магазины существуют; номер карты проходит проверку контрольной цифры; срок `MM/YY`; CVV 3–4 цифры; рефреш не чаще раза в 1,5 с; боевая сборка работает только с apple.com.

## 3. Что расширение делает само, по шагам

1. **Ждёт старта.** Одна вкладка тихо опрашивает сайт Apple (без перезагрузки страницы) и первой замечает, что продажи открылись. Остальные вкладки обновляются по расписанию: редко задолго до старта, раз в ~3 с в последнюю минуту, раз в ~1,5 с после старта.
2. **Открытие.** Как только продажи открылись, все вкладки обновляются вразнобой (0–0,5 с), чтобы не бить по сайту одновременно. Звук и уведомление.
3. **Страница товара.** Дожидается загрузки формы, выбирает «No trade-in» и «No AppleCare+», ждёт, пока кнопка Add to Bag станет активной, жмёт её.
4. **Не уходит со страницы**, пока Apple сама не переведёт дальше — иначе корзина оказывается пустой.
5. **Корзина.** Оставляет одну позицию нужного iPhone, удаляет лишнее, ставит количество 1, жмёт Check Out.
6. **Continue as Guest** — гостевое оформление без Apple Account.
7. **Самовывоз.** «I'll pick it up», город, магазины по очереди (пропускает недоступные), дата, окно самовывоза (сначала в желаемом времени). Если окно заняли — берёт следующее; если в магазине ничего — следующий магазин.
8. **Контакты получателя.** Имя, фамилия, email, телефон, Continue to Payment.
9. **Оплата.** Выбирает способ. Для карты ждёт, пока загрузится блок карты (до 10 с), вводит номер, срок, CVV и адрес плательщика.
10. **Очередь оплаты.** Если заказов несколько — к оплате выходит одно окно за раз, со звуком и уведомлением.
11. **Review Your Order** — нажимает сам.
12. **Review.** Ставит галочку Terms & Conditions. Для Apple Pay жмёт «Continue with Pay», дальше ты сканируешь код телефоном. Для карты (если включено) жмёт «Place Order» один раз, дальше ты подтверждаешь в приложении банка.
13. **Номер заказа.** Ловит номер `W…`, уведомление «Заказ оформлен ✅», сохраняет запись о заказе.

## 4. Защита от сбоев

| Что случилось | Что делает расширение |
|---|---|
| Apple закрыла магазин перед дропом («We'll be back», «Almost ready for you», пустая страница, 404, редирект) | обновляет страницу по расписанию, пока не пустит; уведомления «закрыт» и «открылся» |
| Магазин не открылся вовремя | с момента старта обновляет каждые ~1,5 с |
| Страница очереди Apple | не трогает её до 90 с, чтобы не потерять место |
| Заглушка «Almost there», «busy», 503 | обновляет с паузой, после старта не реже раза в 4 с |
| Баннер выбора страны | выбирает United Arab Emirates; если не уходит — просит проверить VPN |
| Вкладку увело на другой регион | возвращает на страницу товара |
| «Page Not Found» после Add to Bag | пауза и повтор; 5 раз подряд — стоп и диагностика в логе; после 3 неудач — режим ассистента |
| Пустая корзина после Add to Bag | повтор; 3 раза подряд — стоп с уведомлением |
| Лишние товары в корзине | удаляет, оставляет один |
| «Unexpected error / try again» на чекауте | повторяет то же действие до 2 раз, не теряя выбранное окно |
| Окно самовывоза заняли | следующее окно, потом следующий магазин |
| Ошибка в поле («Please enter…») | останавливается и зовёт тебя; после исправления продолжает сам |
| Нет самовывоза ни в одном магазине | доставка (если включена) или уведомление |
| Блок карты долго грузится | ждёт до 10 с, потом переключается на Apple Pay (если включено) |
| Не заполнен адрес плательщика | заполняет из настроек; если в настройках пусто — плашка «заполни сам» |
| Не стоит галочка условий | ставит; если Apple всё же ругнулась — ставит и жмёт оплату ещё раз |
| Ошибка после Place Order | **повторно не жмёт** — сначала проверь почту и номер заказа (12.09 у людей были дубли) |
| Chrome тормозит фоновые вкладки | следящая вкладка остаётся активной, вкладки не выгружаются из памяти, при необходимости опрос берёт на себя фоновая часть расширения |
| Apple переименовала кнопки | ищет их по запасным признакам и тексту («Add to Bag», «Continue as Guest»…); в логе видно, что сработал запасной путь |
| Оплату не подтвердили 10 минут | состояние PAY_TIMEOUT и уведомление |

## 5. Оплата

**Apple Pay:** расширение выбирает Apple Pay, открывает Review, ставит галочку условий и жмёт «Continue with Pay». Если Chrome не открыл окно с кодом от нажатия расширения, кнопка подсвечивается и ты жмёшь её сам. Сканируешь код телефоном и подтверждаешь.

**Карта:** расширение вводит карту и адрес плательщика из настроек, открывает Review, ставит галочку. «Place Order» жмёт либо ты, либо расширение (если включено «Нажимать Place Order самим», один раз). Подтверждение в приложении банка — ты.

Если карта в настройках не задана — расширение ставит курсор в поле карты, вводишь ты.

## 6. Несколько вкладок и профилей

- **В одном профиле Chrome** вкладки делят одну корзину. Add to Bag жмёт только одна вкладка за раз; первая успешная становится главной, остальные останавливаются.
- **Несколько профилей** (Drop 1, Drop 2, Drop 3) можно связать **хабом** — маленькой программой на Mac (`npm run hub`):
  - один профиль следит за открытием и сообщает всем;
  - первый профиль, положивший товар, ведёт заказ, остальные в запасе;
  - когда главный дошёл до оплаты, запасные очищают корзины;
  - если главный упал — заказ передаётся запасному;
  - к оплате выходит одно окно за раз;
  - дашборд в браузере `http://127.0.0.1:8765`: все вкладки всех профилей, кто ведёт какой заказ, очередь оплаты, лог хаба. Личных данных и номеров заказов на дашборде нет — они только в popup своего профиля.
  - хаб слушает только этот компьютер (127.0.0.1); открыть его в сеть можно только явным разрешением.
- Без хаба каждый профиль работает сам по себе.

## 7. Уведомления, звуки, плашка на странице

- **Уведомления macOS:** магазин закрыт / открылся, продажи открылись, нужен твой клик, заказ готов к оплате, ошибки, заказ оформлен.
- **Звуки** (разные): открытие, оплата, нужен клик, ошибка, заказ оформлен.
- **Плашка в углу страницы:** профиль и заказ, текущее состояние, сколько рефрешей и 404, таймер до старта или с момента открытия; кнопки «Пауза» и «Скрыть».
- **Крупный баннер внизу страницы** в важные моменты: «введи карту и нажми Review», «сканируй код телефоном», «поставь галочку», предупреждение про дубли заказов.
- Нужная вкладка сама выходит вперёд, когда требуется твоё действие.

## 8. Режим ассистента

Если автоматическое нажатие не проходит (например, Apple отклоняет Add to Bag) или режим включён вручную: расширение всё подготавливает, подсвечивает нужную кнопку зелёной рамкой, выводит окно вперёд со звуком и ждёт твоего клика. Засчитывается только настоящий клик мышью. После него всё продолжается автоматически. Так же работает с выпадающими списками (город, окно самовывоза), если сайт не принял выбор расширения.

## 9. Лог и данные заказов

**Лог:** каждое действие с точным временем и секундами от открытия продаж, например:

```
[01:06:44.832 +35.770] [drop-1 · A · 2801585] PAYING: на оплату: Apple Dubai Mall · September 30 10:15 – 10:30
```

В лог **не попадают**: токены, cookie, номер карты (только последние 4 цифры), полный email и телефон (маскируются), адрес плательщика. Хранится последние 5000 строк, выгружается кнопкой.

**Записи о заказах** — без масок, только в своём профиле: ФИО, email, телефон, товар, магазин, окно самовывоза, сумма, способ оплаты, время открытия, время выхода на оплату, время оформления, номер заказа. Видно в popup этого профиля, выгружается в CSV оттуда же. В хаб и на другие профили не передаётся.

**Карта** хранится в профиле Chrome открытым текстом. После дропа её нужно стереть в настройках.

**Где хранятся и куда уходят данные:**

| Данные | Где хранятся | Куда уходят |
|---|---|---|
| Конфиг JSON: контакты, карта, адрес плательщика | `chrome.storage.local` этого профиля Chrome | никуда: загружается вручную из файла в каждом профиле, расширение его не скачивает и никуда не отправляет |
| Карта, контакты, адрес | там же | только в форму Apple на своём шаге оформления (это и есть покупка) |
| Записи о заказах: ФИО, email, телефон, номер заказа, сумма | `chrome.storage.local` этого профиля | никуда: смотреть в popup, выгрузка CSV из popup |
| Лог | `chrome.storage.local` этого профиля | никуда: экспорт из popup |
| Хаб | — | получает только: имя профиля, id заказа, приоритет, парт-номера, состояния вкладок, магазин и окно для очереди оплаты, факт «оформлен». Контактов, карты, номеров заказов и строк лога в хабе нет |

## 10. Чего расширение не делает

- не обходит защиту Apple (никаких подмен браузера, прокси, капч, подделки токенов);
- не собирает запросы к Apple руками — только нажимает кнопки на странице, как человек;
- не подтверждает Apple Pay и не подтверждает оплату в банке;
- не жмёт Place Order повторно после ошибки;
- не создаёт вымышленных покупателей.

## 11. Тестовый набор

- **Мок-сервер** — копия сайта Apple на твоём Mac для сухого прогона: «открытие» через 60 с, занятое окно, магазин без наличия, закрытый магазин, медленная карта, подтверждение банка и т.д. Запуск: `./run-mock.command`, расширение из папки `extension-dev` в отдельном профиле Chrome.
- **Готовые настройки для живых тестов** на iPhone 18 Pro: одна вкладка, три вкладки, Apple Pay, три профиля с хабом, Абу-Даби.
- **Автотесты:** 16 сценариев в настоящем Chrome на моке и 13 проверок логики — все проходят.

## 12. Как поставить

1. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → выбрать папку `apple-drop-test-setup` (в ней `manifest.json`).
2. Иконка расширения → Настройки → Импорт JSON (или заполнить форму) → «Проверить и сохранить».
3. За день до старта: Prepare в каждом профиле.
4. В день дропа: Mac на зарядке без сна, VPN выключен, окна не сворачивать, за несколько минут до 16:00 — Start.
5. После дропа: стереть карту из настроек, выгрузить заказы в CSV.
