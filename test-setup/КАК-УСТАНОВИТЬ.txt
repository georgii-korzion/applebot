1. Chrome → chrome://extensions → включить «Режим разработчика» (справа сверху).
2. «Загрузить распакованное» → выбрать ЭТУ папку (apple-drop-test-setup). В ней лежит manifest.json.
3. Откроется страница настроек → «Импорт JSON» → файл из папки live/ (или mock/ для сухого прогона)
   → вписать имя, фамилию, email, телефон 05XXXXXXXX → «Проверить и сохранить».
4. Иконка расширения → Prepare (заранее) → Start (в день теста/дропа).
Подробно — README.md в этой папке.
